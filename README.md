# Dr.NourBot - AI Clinic Assistant 🤖🏥

🚀 **Live Demo:** poe.com/DrNourBot-AI
🔗 **Pinned Project on my Profile**

An intelligent AI Receptionist that books clinic appointments 24/7, built to solve real clinic chaos.

### ✨ What it does
- 📅 Books appointments: Takes Name, Age, Phone, Preferred Date
- 🕒 Answers FAQs: Clinic hours (3PM-9PM), Fees, Location, Doctor info
- 🧠 Smart Correction: Corrects wrong info if user is confused
- 👩‍⚕️ Empathetic & Professional tone, speaks Arabic & English

### 🛠️ Built With
- Poe Platform (Bot Builder)
- Gemini 2.0 Flash
- Prompt Engineering
- Python Logic for booking flow
